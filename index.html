《看得到海的小镇》隐私政策

最后更新：2026 年 11 月 20 日　·　生效日期：2026 年 11 月 20 日

一我们收集哪些信息

游戏本体不收集任何个人信息。

  • 没有账号系统，不需要注册、登录，也不需要手机号、邮箱或第三方账号。
  • 游戏本体没有统计埋点、没有崩溃上报，游戏进度不会上传到任何服务器。
  • 游戏本体不读取通讯录、位置、相册、麦克风、摄像头等敏感信息。
  • 为展示激励视频广告，本游戏接入了第三方广告 SDK，其在广告服务过程中可能处理部分设备信息，详见下文「第三方广告 SDK」。

二第三方广告 SDK

为向玩家提供「看广告解锁建筑」的激励视频功能，本游戏接入了第三方广告服务：

  • SDK 名称：TapADN 广告 SDK（Dirichlet，tapad / com.tapsdk.tapad）；
  • 使用目的：加载并展示激励视频广告，用于建筑解锁奖励；
  • 使用场景：仅在你主动点击「看广告解锁」时加载广告；不观看广告不影响游戏其余功能。

为完成广告投放、反作弊与效果统计，该 SDK 在其服务过程中可能通过系统接口获取下列信息（是否实际获取取决于 SDK 版本、广告类型及你的设备设置）：

  • 网络状态、IP 地址、运营商等网络信息；
  • 设备型号、系统版本、屏幕与语言/地区等基础设备信息；
  • 匿名设备标识（如 OAID / Android ID 等，用于广告归因与个性化）。

我们的隐私设置：在接入层面，我们已关闭 SDK 的可选权限（地理位置、电话状态、Wi-Fi 状态、MAC / BSSID / SSID、传感器、外部存储写入、Android ID 等），仅保留广告展示所必需的能力。你也可以通过系统设置中的广告标识/隐私选项限制个性化广告。

上述信息由广告 SDK 按其自身隐私政策处理，用于广告服务，不会用于识别你的现实身份。广告 SDK 的更多说明以其官方隐私政策为准。

三游戏进度存在哪里

你的岛屿进度（建筑、金币、季节等）只保存在这台设备本地，不会上传到我们的服务器。

具体位置是系统为应用分配的本地存储空间（WebView 的 localStorage）。因此：

  • 卸载应用或在系统设置里「清除数据」，进度就会被删除；
  • 我们无法找回，也没有任何人能远程读取它。

四关于网络权限

应用声明了网络权限，用于两类用途：

  • 系统 WebView 加载安装包内部自带的页面文件（地址是一个仅在应用内有效的虚拟域名，请求全部由应用自身拦截并读取本地资源），游戏本体不发起任何外部网络请求，断网也可完整游玩；
  • 仅在你观看广告时，由第三方广告 SDK 联网获取广告内容，广告加载失败或断网时游戏其余功能不受影响。

五相册权限与照片保存

游戏内有「截图 / 录像」按钮。只有在你主动点击并完成保存操作时，图片或视频才会写入系统相册的「海角小镇」相簿。

  • Android 10 及以上：通过系统媒体库写入，不需要任何存储权限；
  • Android 9 及以下：仅在你点击保存的那一刻申请存储权限，拒绝也不影响游戏。

这些照片只存在你的设备上，我们不会访问、上传或分享。

六未成年人保护

本游戏为单机模拟经营类游戏，无内购、无社交功能。游戏内包含激励视频广告，玩家可自主选择是否观看，观看广告仅用于解锁建筑，不涉及付费。

我们建议未成年人在监护人陪同下游玩，并谨慎点击广告内的跳转内容。家长可使用设备系统自带的「屏幕使用时间 / 数字健康」功能管理孩子的游玩时间。

七你的权利

由于游戏本体不收集、不存储你的个人信息，因此不存在针对游戏本体的「查阅、更正、导出、注销」个人信息的流程。若你希望清除游戏数据：

  • 在系统设置 → 应用 → 《看得到海的小镇》→ 存储 → 清除数据；或
  • 直接卸载应用。

如你希望限制广告 SDK 对设备信息的使用，可通过系统设置中的广告/隐私相关选项进行调整。

八政策更新

如果后续版本新增了需要联网或收集信息的功能（例如云存档、排行榜），或广告 SDK 的数据处理行为发生变化，我们会在更新前修改本政策，并在游戏内和本页面同时说明。

本页面地址即为最新版本，建议以页面上的「最后更新」时间为准。
